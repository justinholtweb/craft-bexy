# Plugin Store promo images

Marketing images for the Bexy listing on the Craft Plugin Store, rendered in the same theme as the
plugin's marketing page at
[justinholt.com/plugins/craft-bexy](https://justinholt.com/plugins/craft-bexy).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `bexy-promo-N.png`, 1920×1080 (rendered at 2× in headless Chrome, then
downsampled so the type stays crisp).

Every slide is pure CSS and type — there are no control-panel screenshots yet. When the CP settles,
screenshot slides can be added alongside these without redoing anything.

**The figures on slide 4 have to add up.** 499.35 + 12.00 − 25.00 = 486.35, and 8.1% included on
that gross is 36.44. An accountant is the target reader; a promo whose arithmetic is wrong argues
against the plugin.

## Editing

Everything lives in `slides.html` — one `<section class="slide">` per image. The palette and fonts
are the plugin site's: accent `#3B82D6`, bexio lime `#81DD01` as the third colour, Jersey 20 for
display, Inter for body.

`fonts.css` is generated by `build.sh` (the woff2 files are base64-inlined so Chrome's `file://`
origin rules can't block them) and is not checked in.

`assets/` holds the fonts and two icon files:

- `icon.svg` — the app icon, used for the cover mark and the footer lockup. Copy it from
  `../src/icon.svg` whenever the icon changes.
- `watermark.svg` — the `bx` mark with the navy tile stripped. The full icon's tile reads as a
  hard-edged box across the slide at watermark scale, which is why the tile goes rather than the
  whole thing being faded further.

## Accent choice

The app icon is bexio's own navy `#0D407E`, but that is too dark to be the site accent: white on it
is fine (10.2:1) while the colour itself on the charcoal background is not (1.9:1). `#3B82D6` is
the lifted version that clears both — 3.9:1 for white button text, 4.9:1 as accent text on
charcoal.
